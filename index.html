Firebase リアルタイム共有の設定

現在の動作：デモモード (ブラウザ保存)

設定未入力時やアクセス権限がない場合は、端末内(LocalStorage)で完全動作します。Firebaseを設定すると他ユーザーの投稿もリアルタイム共有されます。

【重要】Firebaseセキュリティルールの許可設定

Firebase Console → Firestore Database → ルール (Rules) タブを開き、以下を貼り付けて「公開」してください：

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
